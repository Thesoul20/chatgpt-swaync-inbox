## Goal

Consolidate the already-implemented v0.2.5 Hyprland/Firefox click-to-return work into one auditable release boundary, validate behavior and migration/restoration paths, publish the current `main` branch plus the `v0.2.5` tag, and verify that the public repository exposes the accepted README/demo/userscript state.

This is a release-governance task, not a feature-development task.

## Release boundary

The intended v0.2.5 product theme is:

> Reliable explicit click-to-return on Firefox/Wayland through a Hyprland compositor-level fallback, while keeping notification arrival passive and preserving same-tab conversation restoration.

Expected release changes include the coherent set around:

- userscript `@version 0.2.5`;
- short-lived `[ChatGPT Inbox Return]` source-tab marker;
- title-scoped swaync `run-on: action` hook;
- Hyprland focus helper;
- install-state schema v2 plus schema-v1 migration;
- idempotent install and reversible uninstall of rule/action/helper state;
- doctor checks for the focus helper/action integration;
- regression tests for the new configuration/state behavior;
- README/architecture/troubleshooting/security/changelog documentation aligned with the behavior.

Unrelated feature work must not be introduced into this release.
